# Loop Lab — design and credits

Loop Lab is an original identity for WizardLoop: amethyst, precise geometry, mint signal lights, and a loop connecting code, bots, and motion. There is no curated project showcase, view counter, or contact badge.

## Artwork and typography

- The crystal, terminal, bot, and keyframe illustration was generated specifically for this profile using the built-in OpenAI image-generation tool. The source image is [loop-lab-art.png](../assets/loop-lab-art.png); the exact art direction is recorded in [ARTWORK.md](ARTWORK.md).
- The banners are composed by [build_hero.py](../scripts/build_hero.py). Typography is outlined and the illustration is embedded, so SVGs do not fetch third-party images or fonts. A small signal dot pulses once for 2.6 seconds; the main artwork is always visible. Reduced-motion preferences disable the pulse.
- The technology modules, divider, and footer are original vector graphics generated by [generate-identity.py](../scripts/generate-identity.py). Their symbols illustrate tool categories; they are not official product logos.
- **Space Grotesk**, by Florian Karsten, is licensed under the SIL Open Font License 1.1. The font and its [license](../assets/fonts/OFL-SpaceGrotesk.txt) are bundled. Sources: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), [upstream project](https://github.com/floriankarsten/space-grotesk).

Both themes have desktop and mobile compositions. Introductory text remains selectable. Image alternatives describe informative visuals; decorative images have empty alternatives.

## Data and software

- [lowlighter/metrics](https://github.com/lowlighter/metrics), MIT: full-year isometric contribution calendar and contribution statistics.
- [GitHub Readme Stats](https://github.com/stats-organization/github-readme-stats), MIT, through the pinned [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action): repository-local GitHub Stats and Top Languages SVGs.
- GitHub's public Events API supplies recent activity; the repository's renderer escapes event text and applies the same visual palette.
- [david-lev/david-lev](https://github.com/david-lev/david-lev): inspiration for daily generation of local dark/light statistics images. Loop Lab's branding and graphics were created independently.

The toolbox is grounded in public source, manifests, and language metadata: PHP, Python, C, JavaScript, HTML/CSS, Shell, Telegram, Lottie, Docker, and SQLite. Git and GitHub support the work. This is a tool selection, not a proficiency ranking.

Top Languages measures source-code composition in public, non-fork repositories. It does not measure time spent or skill. The contribution calendar can include aggregate private contributions exposed by the existing token; activity entries are public. [Read how the data is generated](METRICS.md).

## Integrations and cost

All displayed assets are stored in this repository. There is no runtime stats service, analytics counter, external font server, WakaTime account, or paid hosting dependency.

The workflow reuses the existing `METRICS_TOKEN` for lowlighter. The automatic `GITHUB_TOKEN` handles public stats, public activity, and commits to this repository. No additional account or secret is required by this implementation. Standard GitHub-hosted runners are free for public repositories; [GitHub's billing documentation](https://docs.github.com/en/billing/concepts/product-billing/github-actions) describes that policy.

Updates run daily at **03:37 UTC**, or manually from **Actions → Update profile metrics → Run workflow**. Scheduled runs begin on the default branch after merge. GitHub may delay schedules or disable them after 60 days of repository inactivity. [Schedule documentation](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

All new data is staged, checked, and published as a complete set. A failed request or invalid render keeps the previous committed set intact. A commit is created only when published content changes. See [METRICS.md](METRICS.md) for the exact workflow and credential details.

## Rebuilding the identity

Install the pinned dependency and run:

```sh
python -m pip install -r scripts/requirements-design.txt
python scripts/build_hero.py
python scripts/generate-identity.py
```

These commands work from the repository root and do not access GitHub or require credentials. The font's SHA-256 is `acad6de1fc93436f5c0f1f4137751ef04f1aea3063e7036535970ffcfbd79f72`.
