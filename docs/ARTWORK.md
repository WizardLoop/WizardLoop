# Original Loop Lab artwork

Created for WizardLoop with the built-in OpenAI image-generation tool. The stored PNG is the original generated transparent asset. The layout and typography are reproducibly composed into SVG by `scripts/build_hero.py`.

The selected design was concept 3, Loop Lab. The final direction removes all specific project cards and adds a larger technology panel. The reference concept is a design study, not a screenshot of live GitHub statistics.

## Illustration prompt

Use case: stylized-concept. Input image is STYLE AND SUBJECT REFERENCE ONLY: the Loop Lab README board. Create a finished standalone hero ILLUSTRATION asset derived from only the reference's upper-right isometric crystal/terminal/bot/animation circuit arrangement. Deliver a genuinely transparent background (alpha), no text, no lettering, no typography, no UI board, no cards, no lightmode miniature, no captions. A single elegant isometric machine-like sculpture: central tall precisely faceted translucent amethyst crystal suspended above two thin floating square graphite-and-violet platforms, a fine luminous orbital ring around the crystal. Three small satellite modules connected by hairline circuits: terminal tile at upper-left with minimal >_ glyph as an icon; charming small geometric robot at upper-right with two square eyes, no facial expression; animation keyframe diamond-node tile at lower-right. Restrained lavender glass edges, graphite metal structure, tiny mint #9CD9C6 signal dots. Refine beyond reference: more delicate bevels, better geometric precision, fewer chunky layers, clear empty space between modules, professional industrial-design silhouette. Deep violet #45316B shadows, soft lavender #B899FF highlights, extremely controlled light, no enormous bloom, no fog, no starfield. Slightly more sophisticated than toy-like 3D, original digital magic and software craft. Center entire cluster with 8% generous transparent padding, do not crop any orbit, light, platform or satellite. Front isometric view, 4:3 broad composition, high detail. It must read beautifully when placed on both near-black #0d1117 and very pale lavender backgrounds. Transparent background mandatory. No external logos.

## Banner composition

Desktop: 1200 × 464. Mobile: 480 × 584. Light and dark compositions use the same original transparent illustration. Lettering uses outlined Space Grotesk. All content is stored locally; no third-party font requests occur at display time.
